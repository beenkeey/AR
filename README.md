# Rig Trigger AR

Новый экспериментальный WebAR-проект: физическая буровая используется **только как одноразовый триггер**. После распознавания виртуальная 3D-модель фиксируется в пространстве и больше не зависит от того, виден ли физический объект.

Это **Этап 1** — технический прототип без визуальных эффектов активации.

## Как запустить локально

Нужны Node.js 18+ и HTTPS: камера на iPhone/iPad Safari не работает с обычным HTTP в локальной сети.

```bash
npm install
npm run generate-assets
npm run dev
```

Vite поднимет HTTPS на порту `5173`. В терминале будет адрес вида `https://192.168.x.x:5173`.

Сертификат самоподписанный. На компьютере в браузере можно продолжить (Chrome: на странице предупреждения набрать `thisisunsafe`). На iPhone Safari: открыть сайт → **Показать подробности** → открыть сайт / доверять сертификату.

## Как открыть на iPhone / iPad

1. iPhone/iPad и компьютер должны быть в одной Wi‑Fi сети.
2. Распечатайте таргет: откройте на компьютере `https://<IP>:5173/print-target.html` и напечатайте изображение (~15–20 см). Закрепите его на физической буровой или поставьте рядом.
3. На устройстве откройте Safari и перейдите на `https://<IP>:5173`.
4. Нажмите по экрану, чтобы разрешить камеру.
5. Наведите камеру на печатный таргет.
6. После появления модели уберите таргет из кадра и обойдите виртуальную буровую.

Debug-панель:

```text
https://<IP>:5173/?debug=1
```

В debug можно нажать **Simulate target found**, чтобы проверить world-lock без печатного таргета (только если SLAM уже инициализировался движением камеры).

## Замена таргета на фото реальной буровой

1. Сфотографируйте физическую модель с главного ракурса, при хорошем свете, без сильных бликов.
2. Замените файл `public/assets/targets/rig-target.png`.
3. Перезапустите dev-сервер. Компиляция MindAR-таргета произойдёт при загрузке страницы.

Пока это image target, а не 3D object scanning: распознавание устойчиво только с похожего ракурса.

## Настройка модели

Параметры в `src/config.js`:

- `model.scale`
- `model.rotationDeg`
- `model.offset`
- `model.url` — путь к настоящему GLB, когда он появится
