# Угольный карьер AR

WebAR-сцена автоматизированного угольного карьера: открытый карьер, БелАЗы на уступах, крупные дроны и экскаваторы. Людей на площадке нет — всё работает автономно.

Физический маркер используется только как одноразовый триггер. После распознавания 3D-мир фиксируется в пространстве.

## Как запустить локально

Нужны Node.js 18+ и HTTPS (камера на мобильном Safari не работает по обычному HTTP в LAN).

```bash
npm install
npm run generate-assets
npm run dev
```

Vite поднимет HTTPS на порту `5173`.

## GitHub Pages

Продакшен-сборка: `https://beenkeey.github.io/AR/`

- **QR** (только открывает сайт): `public/assets/targets/coal-quarry-qr.png`
- **Маркер для камеры** (печатать): `public/print-target.html` → `coal-quarry-marker.png`

Камера распознаёт печатный маркер карьера, а не QR.

## Точки обзора

В AR доступны ракурсы по бровке и уступам, общий обзор карьера и режим следования за движущимся БелАЗом.
